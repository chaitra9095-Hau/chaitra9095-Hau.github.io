Portfolio Website

A responsive personal portfolio website showcasing my profile, activities, technical skills, projects and contact information.
The website features a modern dark-themed design with interactive elements and links to my GitHub and LeetCode profiles.

Tools Used

HTML :
Used to create the structure and content of the portfolio website.


CSS :
Used to design the layout, dark theme, colours, buttons, responsive design, hover effects and glow effects.


JavaScript :
Used to add interactive features such as the cursor-following glow and active navigation.


Git & GitHub :
Used to manage, store and update the website files and track project changes.


GitHub Pages :
Used to publish and host the portfolio website online.


AI Chat Assistant :
Used to generate, improve and refine the website code through prompts.
